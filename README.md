# Nix-hyprland

A tool to **configure** [Hyprland](https://hypr.land) using Nix. Made because
Home Manager's syntax is (in my opinion) pretty bad.

> [!IMPORTANT]
> For basic use, this is ready. But
> [some things](/docs/unimplemented-features.md#other) are broken or not
> implemented yet. I just wanted to get this pushed to GitHub as soon as
> possible and will fix/document/implement a lot of things in the next few days.
>
> For more info, see [Unimplemented Features](/docs/unimplemented-features.md).

## Get Started

Confirm your device fulfills [these requirements](./docs/requirements.md). Then
see the [installation instructions](./docs/installation.md).

If you want (it's not required), you can check out [Options](./docs/options.md).
You'll live without them, though.

After that, you can get to [configuring](./docs/configuring.md)!
