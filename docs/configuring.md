# Configuring

> [!NOTE]
> This section is for Home Manager users only.

Options listed here go in the resulting Lua file.

Nix-hyprland lets _you_ do all the configuring, providing no defaults at all.

> [!WARNING]
> To make that possible, all optional values are `null` by default. So if you
> set them to `null` again, that will not change anything. The resulting Lua
> file will not contain a value of `nil` in that place.

Before reading a section here, it is recommended to first read the corresponding
[Hyprland wiki](https://wiki.hypr.land) page. Here, you will not see available
options or recommendations. This only serves as a guide on how to translate the
syntax you learn on the Hyprland wiki to a Nix configuration compliant with this
flake.

## Native Home Manager

This refers to configuring Hyprland using
`wayland.windowManager.hyprland.settings`. It is fully supported, with no setup
required on your side.

Configuration defined using nix-hyprland will just get merged with the
configuration in `wayland.windowManager.hyprland.settings`.

Inside the Hyprland Lua file, you should see something like:

```lua
-- Generated by Home Manager.
-- See https://wiki.hypr.land/Configuring/Start/
...

-- Generated by nix-hyprland
...
```

So you can clearly see where something was defined.

### Other Configuration Apps

There are other configuration apps (e.g.
[Stylix](https://github.com/nix-community/stylix)) that also add some
configuration for Hyprland.

They may or may not be supported. I'm not omniscient and thus can't know how the
app you're using implements Hyprland configuration, but it should automatically
work with nix-hyprland with no issues. If it integrates with Home Manager, it
_should_ work with nix-hyprland too.

## Lua

You may be dissatisfied with nix-hyprland's implementation of something, and
refuse to use a feature it provides (either due to your preference, it being
bugged, etc.). In such case, you can use
`programs.nix-hyprland.extraLuaConfigPre` and
`programs.nix-hyprland.extraLuaConfigPost` to write Lua code directly.

## Variables

This refers to [these](https://wiki.hypr.land/Configuring/Basics/Variables/).
You can set them like:

```nix
programs.nix-hyprland = {
    decoration.rounding_power = 3.7;
    general.border_size = 10;
    input.touchdevice.enabled = true;
};
```
